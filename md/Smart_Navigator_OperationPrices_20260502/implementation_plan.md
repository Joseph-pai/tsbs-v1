# 智能選股導航操作價格修改計畫

此計畫旨在調整「智能選股導航」的停利計算比例，並在無法計算 20MA 時提供明確的防守停損計算依據提示。

## 預定修改項目

### 1. 後端計算邏輯調整 (`src/app/api/smart-navigator/route.ts`)
*   **調整停利比例**：
    *   `tp1Price` (第一批停利) 的計算由 `buyPrice * 1.3` (30%) 改為 `buyPrice * 1.25` (25%)。
    *   `tp2Price` (第二批停利) 的計算由 `buyPrice * 1.7` (70%) 改為 `buyPrice * 1.50` (50%)。
*   **增加停損來源標記**：
    *   在 API 回傳的 `metrics` 資料中新增一個布林值 `isStopLossFallback`。當 20MA 無法計算（例如上市天數不足 20 天）時，此值為 `true`，代表目前的停損價是使用「最新一日最低價」。

### 2. 前端 UI 介面更新 (`src/app/smart-navigator/page.tsx`)
*   **更新停利文字標籤**：
    *   將「第一批停利 (30%)」更改為「第一批停利 (25%)」。
    *   將「第二批停利 (70%)」更改為「第二批停利 (50%)」。
*   **新增防守停損來源提示**：
    *   在「防守停損」的區塊中加入判斷：若 `result.metrics.isStopLossFallback` 為 `true`，則在標題下方顯示小字提示：「(以最新一日最低價計算)」，讓使用者一目了然。
