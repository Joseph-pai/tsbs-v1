# 智能選股導航列印修復紀錄 (2026-05-11 最終修正版)

## 任務目標
解決當篩選結果過多（如 69 檔股票）時，導致下載的 PNG 檔案為空或無法打開的問題。

## 核心問題分析
1. **畫布極限 (Canvas Limit)**：瀏覽器（如 Safari）對 Canvas 的高度有硬性限制（通常為 16,384 像素）。
2. **像素超限**：69 檔股票在正常縮放下的總高度超過 60,000 像素，遠超瀏覽器處理能力，導致 `toDataURL` 返回空內容。

## 解決方案：動態縮放技術 (Dynamic Scaling)
為了確保超長列表也能成功下載，我實施了以下邏輯：
1. **自動高度偵測**：在截圖前計算內容的 `scrollHeight`。
2. **動態縮放比例**：
   - 如果 (高度 * 1.2) < 16,000px，維持高品質 `scale: 1.2`。
   - 如果超過，則自動計算 `scale = 16,000 / scrollHeight`。例如 69 檔時，縮放會自動調降至約 `0.4`。
3. **記憶體優化**：當進入「超長列表模式」時，自動移除所有卡片的 `box-shadow` 與 `backdrop-filter`。這能大幅減輕瀏覽器渲染壓力，防止崩潰。
4. **渲染等待時間**：將等待時間從 300ms 延長至 **1000ms**，確保大量卡片的顏色燈號完全就緒。

## 結果
- **成功下載**：現在即使是 69 檔股票，也能成功下載出圖，檔案不再為空。
- **穩定性**：解決了瀏覽器因 Canvas 超限而導致的靜默失敗。
