# 智能選股導航 (Smart Navigator) 功能完成

本份文件總結了「智能選股導航」功能的實作細節與異動，主要幫助用戶了解我們所做的更新。

## 功能重點

1. **首頁導航入口**
   - 於主頁（`src/app/page.tsx`）的頂部工具列中，新增了帶有 `Compass` 雷達圖示的「智能選股導航」按鈕。
   - 點擊後會平滑跳轉至獨立的新功能頁面。

2. **極簡化選股導航頁面 (`/smart-navigator`)**
   - 建立了專屬的介面 (`src/app/smart-navigator/page.tsx`)。
   - 支援輸入股票代號（如 2330），並可切換「股價位階」的計算區間（30日、60日、90日、120日，預設為 30日）。
   - **視覺化呈現**：
     - **交通燈號**：根據後端數據直接顯示「綠燈（訊號極佳）」、「黃燈（謹慎觀察）」或「紅燈（風險警告）」。
     - **智能操作價格**：大字體清楚標示「買入建議」、「防守停損」、「第一批停利 (30%)」及「第二批停利 (70%)」。
     - **主力動態解讀**：以條列式的白話文解釋目前籌碼與技術面狀態。

3. **後端智能運算 API (`/api/smart-navigator`)**
   - 新增 API Endpoint (`src/app/api/smart-navigator/route.ts`)。
   - 串接現有的 `FinMindClient` 抓取近百日數據。
   - **實作 MACD 與 EMA 計算**：於 `src/services/indicators.ts` 補齊了 `calculateEMA` 與 `calculateMACD` 函數。
   - **核心判斷邏輯**：
     - 自動計算指定區間的「股價位階 (%)」。
     - 透過比較當日成交量與 5 日均量（>2倍）來定義「換手熱度」。
     - 綜合判斷股價是否站上 20MA、MACD 是否翻紅，進而決定燈號顏色與白話文提示。
