# 「主力動態白話解讀」專業解讀標籤 — 實施計劃

## 目標說明

在智能選股導航頁面的「主力動態白話解讀」區塊，為每個解讀項目新增「**專業解讀**」可點擊標籤，點擊後展開顯示專業分析師思考角度的詳細說明。

## 詳細修改內容

### 1. 擴充 `INTERPRETATION_DETAILS`

目前 7 條 → 擴充為 **13 條**，涵蓋所有 API 可能返回的解讀文字，並以「關鍵字匹配」方式觸發。

每一條都從**專業分析師角度**說明：

| 關鍵字（匹配用） | 新增/強化內容方向 |
|------|------|
| `股價穩站 20 日均線` | 20MA 在技術分析中的意義、多頭防線、分析師如何利用它確認趨勢 |
| `股價跌破 20 日均線` | 破線的嚴重性、法人如何設定停損規則、背後的市場含義 |
| `MACD 維持零軸之上` | MACD 零軸的物理意義、DIF 與 DEA 交叉的信號解讀方式 |
| `相對低位` | 相對位階的計算原理、分析師為何重視「低位」布局、風險報酬比 |
| `相對高位` | 高位追漲的統計風險、法人如何看待高位換手的意義 |
| `中階位置` | 中間位置的不確定性、分析師等待的是什麼信號 |
| `主力積極換手，底部量增` | 底部吃貨的籌碼邏輯、為何量增是確認信號 |
| `低位量縮整理` | 賣壓枯竭的技術意義、風險控制下的試單邏輯 |
| `帶量突破盤整區` | 突破確認的必要條件（量）、分析師的入場確認標準 |
| `價穩量縮，方向待表態` | 盤整階段的操作策略、分析師如何判斷方向 |
| `高位換手熱烈` | 高位籌碼換手的兩種可能性、追高風險的量化評估 |
| `高位量縮，籌碼相對穩定` | 惜售行為的市場心理、持股者應如何應對 |
| `高位爆出天量` | 天量出貨的辨識特徵、主力出貨的常見手法 |

### 2. 改造 UI：將 `HelpCircle` 圖示改為「專業解讀」標籤

**目前：**
```tsx
<button onClick={...}>
    <HelpCircle className="w-4 h-4" />  // 小圖示，不顯眼
</button>
```

**改為：**
```tsx
<button onClick={...} className="...">
    <span className="flex items-center gap-1 px-2 py-0.5 rounded-md 
        bg-indigo-500/15 border border-indigo-500/30 
        text-indigo-400 text-[11px] font-black tracking-wide
        hover:bg-indigo-500/30 transition-all">
        <BookOpen className="w-3 h-3" />
        專業解讀
    </span>
</button>
```

標籤視覺效果：深藍底、indigo 文字、小字體、書本圖示。

### 3. 強化展開區塊的內容結構

**目前：** 純文字說明

**改為：** 結構化顯示，包含：
```
📊 分析師怎麼看：
[詳細說明文字]

💡 操作建議參考：
[基於此訊號的行動建議]
```

`INTERPRETATION_DETAILS` 的 value 改為物件格式：
```ts
type InterpretationDetail = {
    analysis: string;   // 分析師角度說明
    action: string;     // 操作建議
}
```

### 4. 新增 `BookOpen` 圖示 import

在 lucide-react import 中加入 `BookOpen`。

## 驗證計劃

### 人工驗證
1. 在智能選股查詢任一股票，確認「主力動態白話解讀」每個項目末尾顯示「專業解讀」標籤
2. 點擊標籤後展開，確認顯示「分析師怎麼看」＋「操作建議參考」兩段內容
3. 再次點擊收合
4. 換手率資訊行（如 `真實換手率: 3.25%`）無法匹配 → 確認不顯示標籤（正常行為）
