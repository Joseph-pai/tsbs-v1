# 智能選股導航 — 高手版原理說明

> 版本更新日期：2026-05-09

---

## 🎯 主力進場模式

### 核心前提：兩個必要條件

**① 均線多頭排列與支撐（MA5/20/60）**
> 若 `收盤價 < MA20` → 強制紅燈，系統直接跳過所有分析。
> 【高手版強化】加入 MA5、MA20、MA60 均線排列判斷。若低位放量但均線呈現空頭排列（MA5 < MA20 < MA60），降級為黃燈，過濾掉反彈假突破。若是多頭排列，則勝率大幅提升。

**② 計算股價位階（Position %）**
```text
位階 = (當日收盤 - 週期最低) / (週期最高 - 週期最低) × 100%
```
> 判斷目前股價處於歷史的高低位置。低位階（<30%）代表股票還沒漲，主力可能正在悄悄建倉。

---

### 高階輔助指標計算

**① 籌碼集中度評分 (Accumulation Score)**
> 計算過去 60 天內，有多少天滿足「股價在低位（位階 < 35%）且 當日量大於月均量 1.5 倍」。
> 此評分越高，代表主力在底部吸籌的時間越長，籌碼越穩固。

**② KD 超賣底背離**
> 若股價創新低，但 KD 指標的 K 值（在 20 以下超賣區）卻未創新低，形成「底背離」。
> 結合 MACD 低位轉正，形成勝率極高的「底部雙重確認」。

**③ 量比 (Volume Ratio) 異常量警告**
> 量比 = 當日成交量 / 過去5日均量。
> 若量比大於 5，代表出現極端天量。在低位是強勢資金介入，在高位則是暴力出貨警訊。

**④ 大盤相對強弱 (Relative Strength)**
> 比對個股與大盤（TAIEX）近 5 日的表現。
> 若大盤走跌或盤整，但個股多數時間逆勢上漲，代表「主力資金強勢護盤」，後市看漲。

### 主力進場的訊號

#### 🟢 綠燈（主力積極進場，建議跟進）

| 訊號名稱 | 觸發條件 | 主力行為解讀 |
|----------|----------|-------------|
| **低位放量建倉** | 位階<30% + 放量 + 均線非空頭 | 低位出現大量，代表有大資金在底部承接。（若多頭排列則信號更強） |
| **底部雙重確認 (強)** | 位階<20% + MACD轉正 + KD底背離 | 極強轉折訊號。動能轉強且籌碼見底，勝率極高。 |
| **低位縮量蓄勢** | 位階<30% + 縮量 + MACD>0 | 願意賣的人越來越少，籌碼慢慢集中到強者手中。 |
| **底部量能回升** | 位階<30% + 溫和放量 + MACD>0 | 溫和放量代表資金開始試探性進場。 |
| **MACD低位轉正** | 位階<20% + MACD DIF 從負轉正 | 技術面從空轉多的最強轉折訊號。 |
| **主力突破拉升** | 位階30~60% + 放量 | 帶量突破整理區，是最強的追漲訊號。 |

#### 🟡 黃燈（初步佈局訊號，保持觀察）

| 訊號名稱 | 觸發條件 | 解讀 |
|----------|----------|------|
| **逆勢抗跌 (主力護盤)** | 低/中位 + 跑贏大盤天數>=3 | 大盤弱勢但該股不跌，主力強力護盤，隨時準備發動。 |
| **低位放量但趨勢向下** | 低位放量 + 均線空頭排列 | 可能是搶反彈的賣壓，需等待均線糾結轉多。 |
| **主力暗中佈局** | 位階<30% + 量縮 + MACD未轉正 | 「有人在暗中操作但還沒確認」。 |

#### 🔴 紅燈（不納入主力進場篩選）
> 位階>60% 或跌破 MA20 均線 → 不是主力「準備開始」進場的訊號，追入風險極高。

## ⚠️ 出貨預警模式

### 核心前提：位階必須 >60%
> 主力只有在股票已漲到相對高位後，才有意義討論「是否開始出貨」。

### 三大出貨前兆指標

#### 前兆 A：MACD 頂背離
```text
條件：當日股價 >= 前高 × 98%，但當日 DIF < 前高的 DIF
```
> **解讀**：每一次拉高都需要更多力氣，資金的推力在衰退。主力已在悄悄減碼。

#### 前兆 B：量縮伴隨價跌（緩慢派發）
```text
條件：位階>60% + 近5日量縮 + 股價出現較大跌幅 (>3%)
```
> **解讀**：【高手版強化】區分了「高位量縮盤整（洗盤）」與「高位量縮價跌（出貨）」。若量縮且價跌，代表接盤俠耗盡，主力只能以更低價格賣出，出貨權重加倍。

#### 前兆 C：高位橫盤滯漲
```text
條件：位階>60% + 近10日內，最高點距今已超過5個交易日未被突破
```
> **解讀**：多方再也無力攻頂，停止拉升並維持高位，是等待高位賣出機會的行為。

---

### 出貨等級判定邏輯
```text
暴力出貨 = 位階>70% 且 (換手>均值4倍 或 當日長上影線)
（若 量比 > 5 倍，則視為極端天量拋售）

🔴 Alert（風險警告）= 暴力出貨 或 (前兆數>=2 且 放量 且 位階>70%)
🟠 Warning（前期警告）= 前兆數 >= 2
🟡 Watch（謹慎觀察）  = 前兆數 == 1
🟢 Safe（持股安全）  = 位階<=60% 或 無任何前兆觸發
```

**暴力出貨的關鍵特徵 — 長上影線（避雷針）：**
> 盤中大漲但收盤大幅回落，代表主力趁高點大量拋售，散戶接盤，拉高的量都是出貨量，股價最終守不住。

## 📋 操作參考框架

| 燈號/等級 | 狀態 | 操作建議 |
|-----------|------|----------|
| 🟢 主力進場綠燈 | 低位主力積極建倉 | **分批買入**，第一批 30%，等量能持續確認再加碼至 50~70% |
| 🟡 主力進場黃燈 | 初步佈局跡象 | **少量試單** 10~20%，停損設近期低點，等綠燈訊號再加碼 |
| 🟢 出貨預警安全 | 主力持股穩定 | **安心持有**，設移動停利保護獲利 |
| 🟡 謹慎觀察/前期警告 | 出現一至多個衰退前兆 | **停止加碼**，將停利點上移，準備分批減倉計劃 |
| 🔴 風險警告 | 主力明確在出貨 | **立即減倉或停損**，不等反彈，資金保全優先 |

## 系統核心假設

> **主力的行為有跡可循**：主力資金龐大，無法悄無聲息地買賣，必然會在成交量與技術指標上留下痕跡。本系統透過「異常換手率」、「量價關係」、「MACD/KD動能」與「大盤相對強弱」等多個維度，尋找這些痕跡，讓散戶能在主力進場早期發現機會，在主力出場前識別風險。
