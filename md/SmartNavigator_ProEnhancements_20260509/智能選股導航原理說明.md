# 智能選股導航 — 原理說明

> 版本更新日期：2026-05-09

---

## 🎯 主力進場模式

### 核心前提：兩個必要條件

**① 站穩 20 日均線（MA20）**
> 若 `收盤價 < MA20` → 強制紅燈，系統直接跳過所有分析。
>
> **原因**：主力不會在趨勢向下時進場。跌破月線代表多空力道已翻轉，繼續持有或買入都是逆勢行為。

**② 計算股價位階（Position %）**
```
位階 = (當日收盤 - 週期最低) / (週期最高 - 週期最低) × 100%
```
> 判斷目前股價處於歷史的高低位置。低位階（<30%）代表股票還沒漲，主力可能正在悄悄建倉。

---

### 換手率動態計算
```
換手率 = 當日成交量（股）/ 總流通股本 × 100%
20日平均換手率 = 過去20日換手率的平均值
換手倍數 = 當日換手率 / 20日平均換手率
```
> **為什麼用動態倍數而非固定值**：不同股票的成交活躍度不同，用倍數比較才公平。大型股平均換手率可能只有 0.3%，小型股可能達 3%，固定閾值會產生誤判。

---

### 主力進場的五種訊號

#### 🟢 綠燈（主力積極進場，建議跟進）

| 訊號名稱 | 觸發條件 | 主力行為解讀 |
|----------|----------|-------------|
| **低位放量建倉** | 位階<30% + 換手率>均值2倍 | 低位出現大量，代表有大資金在底部承接。散戶通常在低位恐懼不敢買，只有主力有能力大量建倉 |
| **低位縮量蓄勢** | 位階<30% + 換手率<均值0.5倍 + MACD>0 | 願意賣的人越來越少（量縮），籌碼慢慢集中到強者手中。MACD轉正代表趨勢偏多 |
| **底部量能回升** | 位階<30% + 換手率1.2~2倍均值 + MACD>0 | 溫和放量代表資金開始試探性進場，不是急跌後的恐慌拋售 |
| **MACD低位轉正** | 位階<20% + MACD DIF 從負轉正 | 技術面從空轉多的最強轉折訊號，且在極低位發生，代表底部已被確認 |
| **主力突破拉升** | 位階30~60% + 換手率>均值2倍 | 帶量突破整理區，大量買盤在更高價格達成共識，是最強的追漲訊號 |

#### 🟡 黃燈（初步佈局訊號，保持觀察）

| 訊號名稱 | 觸發條件 | 解讀 |
|----------|----------|------|
| **主力暗中佈局** | 位階<30% + 量縮 + MACD未轉正 | 有籌碼集中跡象但動能未確認，是「有人在暗中操作但還沒確認」 |
| **中段縮量整理** | 位階30~60% + 量縮 + MACD>0 | 上漲途中的正常洗盤，主力刻意壓盤清除浮額，準備下一波拉升 |

#### 🔴 紅燈（不納入主力進場篩選）
> 位階>60% 或跌破均線 → 不是主力「準備開始」進場的訊號，追入風險極高。

## ⚠️ 出貨預警模式

### 核心前提：位階必須 >60%
> 主力只有在股票已漲到相對高位後，才有意義討論「是否開始出貨」。

### 三大出貨前兆指標

#### 前兆 A：MACD 頂背離
```
條件：當日股價 >= 前一波高點 × 98%，但當日 DIF < 前一波高點的 DIF
```
> **解讀**：股價創高，但動能指標（DIF）卻比上次更低。每一次拉高都需要更多力氣，資金的推力在衰退。主力已在悄悄減碼。

#### 前兆 B：高位量能遞減
```
條件：位階>60% + 近5日有3日以上成交量低於前一日 + 5日均量 < 10日均量
```
> **解讀**：在高位，願意追入的買盤越來越少，市場熱情退潮。主力很難找到足夠的接盤方，可能正在計劃分批賣出。

#### 前兆 C：高位橫盤滯漲
```
條件：位階>60% + 近10日內，最高點距今已超過5個交易日未被突破
```
> **解讀**：多方再也無力攻頂，停止拉升並維持高位，是等待高位賣出機會的行為。

---

### 出貨等級判定邏輯
```
暴力出貨 = 位階>70% 且 (換手>均值4倍) 或 (換手>2倍 + 當日長上影線)

🔴 Alert（風險警告）= 暴力出貨 或 (前兆數>=2 且 放量 且 位階>70%)
🟠 Warning（前期警告）= 前兆數 >= 2
🟡 Watch（謹慎觀察）  = 前兆數 == 1
🟢 Safe（持股安全）  = 位階<=60% 或 無任何前兆觸發
```

**暴力出貨的關鍵特徵 — 長上影線（避雷針）：**
> 盤中大漲但收盤大幅回落，代表主力趁高點大量拋售，散戶接盤，拉高的量都是出貨量，股價最終守不住。

## 📋 操作參考框架

| 燈號/等級 | 狀態 | 操作建議 |
|-----------|------|----------|
| 🟢 主力進場綠燈 | 低位主力積極建倉 | **分批買入**，第一批 30%，等量能持續確認再加碼至 50~70% |
| 🟡 主力進場黃燈 | 初步佈局跡象 | **少量試單** 10~20%，停損設近期低點，等綠燈訊號再加碼 |
| 🟢 出貨預警安全 | 主力持股穩定 | **安心持有**，設移動停利保護獲利 |
| 🟡 謹慎觀察/前期警告 | 出現一至多個衰退前兆 | **停止加碼**，將停利點上移，準備分批減倉計劃 |
| 🔴 風險警告 | 主力明確在出貨 | **立即減倉或停損**，不等反彈，資金保全優先 |

## 系統核心假設

> **主力的行為有跡可循**：主力資金龐大，無法悄無聲息地買賣，必然會在成交量與技術指標上留下痕跡。本系統透過「異常換手率」、「量價關係」與「MACD動能」三個維度，尋找這些痕跡，讓散戶能在主力進場早期發現機會，在主力出場前識別風險。
