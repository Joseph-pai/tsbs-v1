## 強化1：均線多頭排列（⭐⭐⭐）

### 目標
減少假突破誤判，提升綠燈可信度。

### 算法
```
MA5  = 最近5日收盤價的簡單移動平均
MA20 = 最近20日收盤價的簡單移動平均（已有）
MA60 = 最近60日收盤價的簡單移動平均

多頭排列 = MA5 > MA20 > MA60  → 趨勢確認向上，綠燈加分
空頭排列 = MA5 < MA20 < MA60  → 趨勢確認向下，即使量能放大也降低可信度
```

### 實作邏輯
- 低位出現綠燈訊號 + 多頭排列 → 在 rules 中加入「多頭排列確認，趨勢向上可信度高」說明
- 低位出現綠燈訊號 + 空頭排列 → 降級為黃燈，並加入警示說明
- 回傳 `metrics` 中加入 `ma5` 和 `ma60` 數值

### 修改檔案
- `src/app/api/smart-navigator/route.ts`

## 強化2：洗盤 vs 出貨的股價方向區分（⭐⭐⭐）

### 目標
解決高位量縮被誤判的問題：鎖倉 ≠ 出貨。

### 算法
```
近5日股價方向 = 用線性迴歸斜率 或 比較首尾
  - 若高位量縮 + 近5日股價未見明顯下移（波動<3%）→ 鎖倉惜售（安全）
  - 若高位量縮 + 近5日股價緩慢下移（跌幅>3%）     → 緩慢出貨（升級警示）
```

### 實作邏輯
- 在出貨前兆 B（高位量能遞減）判斷時，額外判斷近5日股價是否下移
- 若量縮同時伴隨價跌 → `isVolumeDeclineAtHigh` 的可信度加倍，在 `distributionLevel` 計算中視為「2個前兆」的效果
- 在 `signalTag` 說明中新增「股價同步下移」的文字提示

### 修改檔案
- `src/app/api/smart-navigator/route.ts`

## 強化3：籌碼集中度評分（⭐⭐）

### 目標
顯示「主力已佈局多久」，讓用戶有更多時間依據。

### 算法
```
吸籌評分 = 過去60日中，符合以下條件的交易日數量：
  - 股價位階 < 35%（低位）
  - 成交量 > 近20日均量 × 1.5

評分解讀：
  ≥ 10 天 → 主力重度佈局（高確信）
  5~9 天  → 主力中度佈局（中確信）
  1~4 天  → 主力輕度試探（低確信）
  0 天    → 無吸籌跡象
```

### 修改檔案
- `src/app/api/smart-navigator/route.ts`（新增 `accumulationScore`）
- `src/app/smart-navigator/page.tsx`（在綠燈卡片中顯示籌碼評分徽章）

## 強化4：KD 超賣底背離（⭐⭐）

### 目標
讓低位買點有雙重技術確認，提升勝率約30%。

### 算法
```
KD 指標（隨機指標）：
  RSV = (當日收盤 - 近9日最低) / (近9日最高 - 近9日最低) × 100
  K值 = 前一日K × 2/3 + RSV × 1/3
  D值 = 前一日D × 2/3 + K × 1/3

底背離條件：
  - 當前 K 值 < 20（超賣區）
  - 股價低於20日前的低點，但 K 值高於20日前的 K 值

觸發加分：MACD DIF 低位轉正 + KD 底背離 → 強力買點確認
```

### 修改檔案
- `src/services/indicators.ts`（新增 KD 指標計算）
- `src/app/api/smart-navigator/route.ts`（引用 KD，加入底背離判斷）

## 強化5：量比（Volume Ratio）（⭐）

### 目標
比換手率更即時的異常量強度判斷。

### 算法
```
量比 = 當日成交量 / 過去5日平均成交量

量比 > 5     → 極端大量（天量）
量比 2~5     → 明顯放量
量比 0.8~2   → 正常量能
量比 < 0.5   → 極度萎縮（鎖倉）
```

### 修改檔案
- `src/app/api/smart-navigator/route.ts`（計算 `volumeRatio` 並加入 metrics 回傳）

## 強化6：大盤相對強弱（⭐）

### 目標
找出真正被主力拉抬的逆勢強勢股。

### 算法
```
相對強弱 = 當日個股漲跌幅 - 同日加權指數漲跌幅

連續相對強弱 = 計算近5日每日相對強弱，並統計正值天數

若近5日有3天以上相對強弱>0，且位在低位 → 逆勢抗跌，主力力撐訊號
```

> ⚠️ 注意：需要抓取台灣加權指數（^TWII 或 TAIEX）的每日數據，需確認數據源可用性。

### 修改檔案
- `src/lib/exchange.ts`（新增大盤指數抓取方法）
- `src/app/api/smart-navigator/route.ts`（引用大盤數據，計算相對強弱）
