# 智能選股導航 - 自動篩選功能實作計畫

這個計畫旨在於「智能選股導航」頁面新增「自動篩選」功能，允許用戶從歷史掃描紀錄中快速篩選出符合綠燈標準的潛力股。

## User Review Required

> [!IMPORTANT]  
> 1. **資料來源**：計畫會從 Firebase 中的 `scan_history` 抓取用戶過去掃描出的股票做為過濾清單。請確認這是否符合您所說的「數據庫裡的歷史紀錄的股票」。
> 2. **漸進式過濾邏輯**：計畫設計為批次向後端 API 請求每檔股票的數據，先排除 `位階 (Position %) > 設定的相對高位%值` 的股票（快速條件），接著再檢查最終燈號是否為 `green`（綠燈）。
> 3. **顯示方式**：多檔綠燈股票會以列表方式垂直呈現，每個區塊都會包含「股票代號與名稱」以及原本單檔查詢時出現的「燈號、價格、主力動態解讀」完整內容。

## Proposed Changes

### [MODIFY] `src/app/smart-navigator/page.tsx`
- **引入與狀態新增**：
  - 引入 Firebase 的 `getScanRecords` 與 `MiniCalendar` 相關日曆組件依賴（如 `date-fns` 等，參考 `HistoryModal.tsx`）。
  - 新增狀態控制自動篩選的面板開關 (`showAutoFilter`)、選取的日期、相對高位設定 (`maxPosition`)、篩選進度 (`filterProgress`) 以及篩選出的多檔結果清單 (`filterResults`)。
- **UI 佈局調整**：
  - 在原有的「開始導航」旁邊新增一個「自動篩選」按鈕。
  - 點擊「自動篩選」展開面板，顯示：
    1. **月曆元件**：顯示有歷史數據的日期（打點），點擊選取日期。
    2. **參數設定**：數據日期區間（30/60/90/120天）與相對高位%值（50%/60%/70%）。
    3. **執行按鈕**：點擊後開始掃描。
- **自動篩選邏輯 (`handleAutoFilter`)**：
  - 取出選定日期當天所有的歷史掃描股票清單並去重。
  - 使用進度條顯示目前進度，以小批次（例如 5 檔）並發請求 `/api/smart-navigator`。
  - **條件過濾**：
    1. 快速過濾：`metrics.positionPercent <= maxPosition`
    2. 綠燈過濾：`light === 'green'`
  - 若皆未符合，顯示「無符合條件」。
- **結果渲染抽離/重構**：
  - 將原本單筆顯示的 Result Area 抽成可複用的區塊。當自動篩選完成時，使用迴圈渲染每一檔符合條件的股票，並在頂部加上「股票代碼與名稱」。

## Verification Plan

### Manual Verification
1. 進入智能選股導航頁面，點擊「自動篩選」。
2. 確診月曆能正確標示並點擊具有歷史掃描紀錄的日期。
3. 調整日期區間與相對高位 % 值。
4. 點擊開始掃描，確認進度條正常運作，且篩選過後只顯示綠燈的股票（或正確顯示「無符合條件」）。
5. 檢查顯示的內容是否包含股票代號、名稱以及完整的紅綠燈與價格區塊。
