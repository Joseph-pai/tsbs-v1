# 增加「黑馬預測」功能實作計畫

根據您的需求與先前的飆股分析結論，我們將在掃描結果頁面（定點共振掃描與強化評分掃描）加入一個「黑馬預測」按鈕。點擊後，系統將使用**複合條件**來精準篩出具有翻倍潛力的低基期股票。

## Proposed Changes

### src/app/page.tsx

#### [MODIFY] src/app/page.tsx
1. **新增狀態變數**:
   ```typescript
   const [showDarkHorseOnly, setShowDarkHorseOnly] = useState(false);
   ```

2. **定義「黑馬股」複合條件邏輯**:
   在 `filteredResults` 和 `filteredEnhancedResults` 中加入黑馬過濾器。一檔股票必須**同時符合以下 (A) 與 (B) 兩項條件**，才會被判定為黑馬：

   - **(A) 中低評分 (低基期)**：
     - 綜合評分 `<= 86` 分。

   - **(B) 滿足「族群群聚發動」或「單一突破標籤」其中之一**：
     - **族群群聚發動**：動態計算本次掃描結果中的產業分佈。如果該股所屬的「產業類別」在本次掃描結果中出現 **2 檔（含）以上**（代表資金正在匯聚該板塊），則符合條件。
     - **單一突破標籤（營收公布前夕或營收爆發）**：該股具備以下任一強勢特徵：
       - `isRevenueNewHigh` (營收創近期新高)
       - `is_ma_breakout` (均線突破)
       - `tags` 中包含 `'BREAKOUT'` (帶量突破)

3. **排序規則**:
   過濾出符合上述複合條件的股票後，按照**評分從高到低（降冪）排列**。

4. **UI 修改**:
   在掃描結果區塊（原始掃描與強化掃描）的右上角，緊鄰「匯出為 PDF」按鈕的旁邊，新增一個「🐎 黑馬預測」切換按鈕。點擊後即套用上述邏輯。
